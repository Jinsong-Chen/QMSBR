Before you start

A command is one instruction for R, such as mean(score). An object is a named value R keeps for later, such as score. The assignment arrow <- creates one: score <- 60 stores 60 under the name score, and typing score on its own line prints it. c() combines several values into one vector, so c(50, 54, 48) holds three scores. $ takes one named column out of a table: dat$score is the score column of dat. A function is a command that does a job, written with its arguments inside the brackets. In t.test(special, usual, var.equal = FALSE) the first two arguments supply the data and var.equal = FALSE is a named setting; commas separate them, and text in quotes is a label rather than an object. Names must match exactly, so Mean is not mean. For the buttons, the keyboard shortcuts and what to do when R reports an error, see how to run code.

Normal areas and z scores

A z score reports how many SDs a value lies from its mean: z <- (score - mu) / sigma. pnorm(z) returns the lower-tail area below z under the standard Normal curve, and pnorm(z, lower.tail = FALSE) returns the area above it. qnorm(p) reverses the question: it returns the cutoff whose lower-tail area is p. An area between two bounds is the difference of their cumulative probabilities, so pnorm(1) - pnorm(-1) gives the central area within one SD.

The z score is 2.0000, with lower area .9772 and upper area .0228. The central areas are .6827, .9545 and .9973, and the central-95% bounds are -1.9600 and 1.9600. Changing score moves one value’s position; changing a confidence level changes a reference cutoff. Neither turns an individual SD into the SE of a mean.

Build an interval from supplied values

Core Exercise 4 supplies the estimate, SE and critical value below. Use them to calculate its 95% interval. The book explains the approximate Welch procedure and how to interpret the interval.

<- stores a value under a name. c() joins values. Arithmetic works element by element, so c(-1, 1) subtracts and adds the margin to make the two endpoints. sprintf("%.4f", interval) displays four decimal places, including trailing zeros. It returns text for reporting; the numeric object interval keeps its full precision for later calculations.

The interval is [0.8571, 5.3429] points. For a small programming experiment, change only estimate to 2.1 and rerun. Both endpoints move down by one point while the width stays the same. Restore estimate <- 3.1 before answering the exercise.

One mean: known SD or estimated SD

These are two different assumptions about the SD, shown with the same numerical spread. A stipulated population SD of 5 gives a z calculation; a sample SD of 5 from 25 observations gives a t calculation with n - 1 degrees of freedom. pt() returns a t-distribution probability, so 2 * pt(-abs(t_value), n - 1) is a two-sided p-value. Choose the procedure from what is actually known about the SD. Do not switch to the other one because it crosses a significance threshold.

Both statistics are 2.0000; the z p-value is .0455 and the t(24) p-value is .0569. These summaries do not reconstruct 25 unobserved raw scores. With an actual vector of scores, t.test(x, mu = 50) performs the same one-sample t test from the data themselves.

Numbers and a known SD

For a supplied vector of scores, length(), mean() and sd() return the count, average and sample SD. sqrt() takes a square root. Copy these commands into your workspace to try them:

scores <- c(12, 15, 17, 18, 20)
length(scores)
mean(scores)
sd(scores)
sigma <- 4
se <- sigma / sqrt(length(scores))
se

Here sigma is a separately stipulated population SD, while sd(scores) describes the entered sample. Homework 9 supplies its own complete code, scores, known SD and critical value. Use those inputs for its interval. Native R output can show a different number of digits; use four decimals when recording calculated results.

Sample size and the t reference

Hold the mean difference and the SD fixed and change only the sample size, so the SE and the degrees of freedom are the only moving parts. data.frame() places the results side by side in one small table. These are two stipulated summaries for two hypothetical samples; a larger real dataset would not keep exactly the same mean and SD, and a large sample must never be created by duplicating the same observations.

The SE falls from 1.5811 to 0.5000, the statistic rises from 1.2649 to 4.0000, and the reference distribution changes from t(9) to t(99). This comparison is about precision and the reference tail; it is not a rule for choosing a test at some fixed sample size.

Compare two groups

The Special Practice CSV has 120 fictional participants, 60 per assigned condition, with complete delayed assessment scores on a 0-40 scale. The data register gives the invented design and explains the CSV’s relationship to the book.

read.csv() reads the named file into a table. $ chooses a column; == matches a label, and [] selects the scores with that label. table() counts the groups and head(dat) shows the first six rows. Keep the original data in d0 and use dat as the working copy for every later calculation.

t.test(special, usual) compares the first mean minus the second. var.equal = FALSE requests Welch’s unequal-variances procedure and var.equal = TRUE pools the two variances; conf.level sets the confidence level. The returned object contains the test and interval; $stderr selects its estimated SE and $conf.int its endpoints.

The difference is 3.1000 points, the Welch SE about 1.1324 and the Welch 95% interval about [0.8575, 5.3425]. With this balanced CSV the two SEs coincide, while the degrees of freedom (about 117.51 against 118) and the critical values differ slightly. That arithmetic coincidence does not establish equal population variances. Compare the method labels, df and conditions rather than only which p-value is smaller. The Computer Lab uses the Welch procedure and its confidence change below.

Read the printout line by line

Every t.test() result prints in the same fixed layout, so reading this one carefully makes the others familiar. This is the welch output from the cell above, unchanged.

    Welch Two Sample t-test

data:  special and usual
t = 2.7376, df = 117.51, p-value = 0.007152
alternative hypothesis: true difference in means is not equal to 0
95 percent confidence interval:
 0.8574549 5.3425451
sample estimates:
mean of x mean of y
     27.1      24.0
  • The first line names the procedure: Welch’s two-sample t test, the unequal-variances one. Running the pooled call prints Two Sample t-test instead.
  • data: names the two vectors in the order you gave them, so the comparison is Special minus Usual.
  • On the fourth line, t = 2.7376 is the test statistic, df = 117.51 its degrees of freedom and p-value = 0.007152 the two-sided p-value, which is .0072 to four decimals. The df are fractional because Welch approximates them from the two sample variances; the pooled call reports 118.
  • The alternative hypothesis: line states what that p-value is calculated against: a true difference of zero, with both tails counted.
  • The two numbers under 95 percent confidence interval: are the interval endpoints, [0.8575, 5.3425] points. welch$conf.int returns the same pair, and conf.level changes them.
  • Under sample estimates:, mean of x 27.1000 and mean of y 24.0000 are the two group means. Their difference, 3.1000 points, is the estimate the interval is built around.

The printout does not show the SE. welch$stderr returns it: 1.1324 points. The interval is the estimate plus and minus the critical value for those df times that SE, which is how the interval and the test use the same quantities.

One confidence change

In the two-group example, level <- 0.95 sets the confidence level. Change only that line to level <- 0.90 and choose Run All. Read the new interval in welch$conf.int; diff(welch$conf.int) gives its width. Compare it with the original interval, then restore level <- 0.95. The same participants and scores supply the estimate, SE and two-sided p-value. A narrower interval at a lower confidence level reflects a different coverage requirement; it adds no observations or information.

The row and display changes below are reference examples. Use the change specified in your task rather than completing every variation.

Use supplied summary values

For core Exercise 2, enter its group counts and sample SDs directly. ^2 squares each SD; division by its group count gives that group’s contribution to the working variance. Add them before taking the square root. Copy this short calculation into your workspace.

n1 <- 60
n0 <- 60
s1 <- 6.0
s0 <- 6.4
sqrt(s1^2 / n1 + s0^2 / n0)

The same formula covers an unbalanced reference case: change only one declared group count, such as n0 <- 40, and read the larger SE. That is a reference step with stipulated summaries, not a new dataset.

Change the data and rerun

Replace only dat <- d0 in the two-group cell with the following line, then choose Run All to rerun the complete calculation:

dat <- d0[-(1:3), ]

1:3 means rows 1 through 3. A negative row index removes those rows; the empty place after the comma keeps all columns. Alternatively, use:

dat <- head(d0, -3)

head() with a negative count keeps all except the last three rows. The file begins with Special Practice and ends with Usual Practice, so the alternatives affect different groups. Keep both groups populated. Rerun the whole cell and compare group counts, means, the difference, SE and interval. Restore dat <- d0 and rerun to recover the starting result. These file-order exclusions change the analysed records; they are programming experiments, not random sampling or a remedy for missingness.

For a task that reverses the comparison, reverse both the t.test() inputs and the explicit subtraction in the line that prints difference. Multiplying both score vectors by the same positive number changes the measurement units. Use the complete script and settings supplied with that task.

Paired scores

These eight invented students were measured before and after one short practice session, on the same score scale at both times. They are not Special Practice records. Define the difference difference <- after - before before calculating anything, so the direction is after minus before.

paired = TRUE tells t.test() to analyse the within-student differences. The second call performs the same one-sample test on the differences themselves, and returns the same statistic, df, p-value and interval.

The mean difference is 2.0000 with SD 2.0000 and SE 0.7071, giving t(7) = 2.8284, p = .0255 and the 95% interval [0.3280, 3.6720]. The paired SE uses the variance of the differences, which subtracts twice the covariance between the two measurements; the independent-samples formula omits that covariance because it describes a different design. A before-and-after difference alone cannot separate the session from time trends, repeated testing or other concurrent changes.

A connected paired-score plot

cbind() places the two measurement columns side by side and t() transposes them, so each student becomes one column with two rows. matplot() then draws one line per student across the two measurement positions. type = "b" draws both points and lines, xaxt = "n" suppresses the default numeric axis, and axis() labels positions 1 and 2.

Each line joins the same student across measurements. Most lines rise, one is flat and one falls; the paired test summarizes those eight within-student changes rather than two separate group averages.

Covariance and correlation

cov(x, y) reports how two measurements vary together in their original product units, so its size depends on the measurement scale. cor(x, y) divides by both SDs and is unit free, between -1 and 1. Multiplying x by 10 is a positive unit change: the covariance is multiplied by 10 while the Pearson correlation is unchanged. method = "spearman" correlates the ranks instead of the values and describes monotonic association, as introduced in Chapter 2.

The covariance 28.1429 becomes 281.4286 while Pearson’s r stays .9599; the Spearman rank correlation is .9222. These are the same eight paired scores used above. A correlation describes association in these records; it establishes no causal direction and is not a regression coefficient.

Base R graphs

Each graph below runs in its own cell with its own data-loading line, so you can run any one of them on its own. All of them use base graphics; no plotting package is needed. Read the axis labels and the statistic being displayed before interpreting a picture.

A histogram of all scores

hist() counts observations within score intervals. breaks = 10 is a suggestion for the number of intervals, main titles the plot and xlab names the horizontal axis. The bar heights are counts, not probabilities.

This histogram pools both practice groups, so a difference between them is not visible here.

A smoothed density curve

density() smooths the same scores into a continuous curve, and plot() draws it. The curve’s shape depends on the smoothing bandwidth reported in its output; it is an estimate, not the recorded data.

Boxplots by group

In score ~ group, ~ reads as “by”: one box per group label. A box shows the median and quartiles, the whiskers reach most of the remaining values, and separate points mark values far from the box.

The grouped boxplot makes the group structure visible that the pooled histogram hides. Its line is the median, not the mean estimated by the t comparison above.

A bar chart of two categories

These counts are one 50-person row of the count table below: the online participants who completed and who did not. barplot() draws one bar per named count, and ylab names the axis.

The same two categories as a pie

pie() shows the same two counts as shares of the 50 online participants. Bar lengths support more accurate comparison than pie angles, so prefer the bar chart when the exact sizes matter.

The denominator is the 50 online participants only. Do not draw the four cells of the two-by-two table as though they were four independent participation categories.

A scatterplot of two measurements

plot(x, y) draws one point per pair. abline(a = 0, b = 1, lty = 2) adds a dashed line with intercept 0 and slope 1, marking equal scores: points above it improved and points below it declined.

The points rise together, which is the association summarized by covariance and correlation; their distance from the dashed line is the within-student change tested in the paired example.

Run a supplied exercise script

The Computer Lab supplies the complete Special Practice script. Other exercises or their reference material supply any UCI or private HSB setup they use. If a script uses a bare CSV filename, open that CSV in the workspace first, or change its first file path to the public data/... path shown with the example. Paste all the setup and analysis into the workspace and run it together. Public CSVs listed on this page are already available there as data/...; on desktop R, keep that subfolder or change the path to your downloaded file. The supplied homework 9 code needs no CSV.

For variations in a supplied script, t.test(x, mu = ...) compares one mean with a stated value; paired = TRUE uses matched differences, var.equal = TRUE pools the variances and alternative states the test’s direction. Choose those settings from the study and the assigned question. pnorm() returns a Normal probability; qt() returns a t critical value. The chapter and task specify the model and any supplied critical value.

The worked count table

matrix(..., nrow = 2, byrow = TRUE) fills two rows in order, and dimnames names the rows and columns. Here the rows are the two participation formats and the columns are completion and its absence. prop.table(counts, 1) divides by each row’s total, so the two row proportions use the 50-person denominators. chisq.test(..., correct = FALSE) requests the ordinary Pearson calculation; the default two-by-two continuity correction answers a related but different question. $expected shows the counts predicted when format and completion are independent.

The completion proportions are .6400 and .3600, a difference of .2800 in the Online-minus-In-person order. All four expected counts are 25, giving X-squared 7.8400 with 1 df and p = .0051. These are invented records for an association question: participation format was not assigned, so the result supports no causal claim. Exercise 7 has its own table and counts; use its numbers, not these.
