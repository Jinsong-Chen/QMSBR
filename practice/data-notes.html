Data sources for browser statistics practice

The browser statistics activities use a synthetic practice record, an observational record of secondary-school students, an invented feedback-by-practice quiz record, a published reading instruction record, and archived numerical scores used in an invented factorial teaching setting. Each supports a different kind of comparison. This note explains what the records contain, where they come from, and how they may be reused.

Use this list to find the data for your chapter; the sections below give downloads, column explanations, source context, and reuse terms.

Data Chapter Access
Special Practice 3 Public CSV; fictional teaching records.
UCI Student Performance extract 3 Public CSV; observed groups and passing status.
Feedback and practice quiz scores 4 Public CSV; invented one-way and factorial teaching data.
Reading instruction Reference carData::Baumann; prepared in the shared workspace.
Review timing Reference Public CSV and codebook; archived factorial scores.

Use short, meaningful names in your code. Keep starting data in d0 and a working copy in dat when changing rows. Report calculated statistical results to four decimal places, keeping full precision for calculations. Input precision or software rounding may slightly change the last digits.

Four CSV files are available below. Each uses a comma as the delimiter and has variable names in its first row. The reading instruction data are obtained directly from the carData R package; no extract of that dataset accompanies this note. The reading instruction and review-timing records remain available for reference consumers and the shared workspace; the Chapter 4 page uses the feedback and practice scores instead.

Synthetic Special Practice record

Download the Special Practice data (CSV)

This QMSBR record contains 120 fictional participants: 60 assigned to Special Practice and 60 to Usual Practice. The imagined study compares two practice formats with four sessions and equal total study time. A common assessment, scored from 0 to 40 points, takes place two weeks later. These are constructed teaching records, not observations from an actual experiment.

Field Meaning and coding
id Artificial row identifier, C3-001 through C3-120; it has no personal meaning.
group Special Practice or Usual Practice, with 60 records in each condition.
score Integer score on the common delayed assessment, in points on a 0–40 scale.

The concise headers id, group, and score replace the earlier student_id, assigned_condition, and delayed_score headers. The records and their order are unchanged.

All 120 records are retained, and the three fields contain no missing values. The comparison direction is Special Practice minus Usual Practice. The assignment and follow-up details belong to the invented study description; the values alone do not establish a research design.

The supplied rows define a fixed teaching record. Calculate software results from those rows and retain their full precision during analysis. Use these records for CSV tasks and the inputs supplied in each core exercise for its calculations.

Reuse. QMSBR dedicates this synthetic CSV to the public domain under CC0 1.0 Universal. The dedication applies to the CSV. Retain its description as synthetic when presenting or adapting it.

UCI Student Performance extract

Download the UCI groups data (CSV)

This extract retains all 395 records from the mathematics file in Paulo Cortez’s Student Performance dataset. The source records concern students in two Portuguese secondary schools. Higher-education intention was observed, not assigned. One row represents one recorded student.

Source and attribution. Cortez, P. (2008). Student Performance [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5TG7T. The UCI dataset page provides the source files and variable documentation.

QMSBR prepared this three-column extract through a curated copy of the mathematics data. All rows remain in their source order. The adaptations are the addition of an artificial identifier, selection and renaming of fields, and derivation of pass status from the recorded final grade.

Field Source, meaning, and transformation
id Artificial identifier U001 through U395, added by QMSBR as student_id in the curated copy and renamed here. It is not an original participant identifier.
higher Source field higher, retained as higher_education in the curated copy and renamed here. yes means the student reported an intention to pursue higher education; no means the student reported no such intention.
pass Derived from source final grade G3, retained as pass in the curated copy and renamed here. Yes means a grade of at least 10 on the 0–20 scale; No means a grade below 10.

The three supplied fields have no missing values. There are 375 yes intention records and 20 no intention records. For a passing proportion within an intention group, use that group’s total as the denominator. The comparison direction is intention yes minus intention no, with the result interpreted as an observed association in this record.

Recorded zero grades. The source documentation marks the dataset as having no missing values, but the source mathematics file contains an unresolved pattern: 38 records have final grade zero and zero absences, and 25 of those also have a positive second-period grade. The documentation does not establish a common meaning for all these zeros. The primary comparison retains grades as recorded. Omitting the zero-grade records is a diagnostic check that changes the analysed set, rather than an established correction.

Grades and absences are absent from this three-column extract. It therefore cannot identify the zero-grade records or reproduce that diagnostic exclusion. Interpret any supplied diagnostic results alongside this limitation.

Reuse. The source and this extract are licensed under Creative Commons Attribution 4.0 International. When redistributing or adapting the extract, credit Cortez and the UCI Machine Learning Repository, retain the source and licence links, and identify QMSBR’s adaptations and any further changes you make. The licence does not imply endorsement by the source creators.

Feedback and practice quiz scores

Download the feedback and practice data (CSV)

This QMSBR record contains 24 invented Grade 7 students, each measured once on a fractions quiz scored from 0 to 20. The imagined study crosses three feedback conditions with two practice schedules, giving six cells of four different students. The Chapter 4 page uses the 12 Massed-practice rows for its one-way example and all 24 rows for the full factorial model.

Field Meaning and coding
student Sequential identifier 1–24; it has no personal meaning.
feedback Rereading, Answer feedback or Explanatory feedback, in that teaching order.
practice Massed or Spaced, in that teaching order.
score Integer quiz score in points on a 0–20 scale.

A CSV stores these labels as plain text, so R orders them alphabetically unless the script declares the order. Every analysis sets levels = c("Rereading", "Answer feedback", "Explanatory feedback") and levels = c("Massed", "Spaced") with factor() before fitting a model.

The 24 scores are fixed authored values, not a sample generated at render time, and the repeated residual pattern is deliberate so the arithmetic stays visible. They are teaching records: they do not validate a Normal model, equal variances, or any real effect of feedback or practice scheduling. There are no missing values and no student appears twice.

Maintained provenance. The canonical file, its complete score table and the full preparation record belong to the Chapter 4 technical document in the course materials, under its data section ch04-data-feedback-practice. This page redistributes only the identity and dictionary its readers need; the copy here is verified byte for byte against that canonical file.

Reuse. QMSBR dedicates this synthetic CSV to the public domain under CC0 1.0 Universal. Retain its description as invented teaching data when presenting or adapting it.

Reading instruction data from carData

This reference example uses Baumann from carData: Companion to Applied Regression Data Sets, by John Fox, Sanford Weisberg, and Brad Price. The package documentation for Baumann describes 66 records with a group field, two pretests, and three post-tests. It traces the teaching dataset to Moore and McCabe’s Introduction to the Practice of Statistics (2nd ed., 1993, pp. 794–795).

Once carData is available in R or WebR, load the dataset explicitly and prepare a working copy with the activity’s group labels:

data("Baumann", package = "carData")
d0 <- Baumann
dat <- d0
dat$score <- dat$post.test.1
dat$group <- factor(
  dat$group,
  levels = c("Basal", "DRTA", "Strat"),
  labels = c("DRA", "DRTA", "Think-aloud")
)

This code keeps the package record in d0, copies it to dat, gives the selected outcome the short name score, and changes the working group labels. It retains all 66 observed records and their scores. The outcome used here is post.test.1, the selected error-detection score in points on a 0–16 scale. The original package object remains available as Baumann.

Package label Activity label Assigned children Observed outcomes
Basal DRA: directed reading activity 22 22
DRTA DRTA: directed reading-thinking activity 23 22
Strat Think-aloud instruction 23 22

The study description and assignment counts come from Baumann, Seifert-Kessell, and Jones (1992), Effect of Think-Aloud Instruction on Elementary Students’ Comprehension Monitoring Abilities, particularly the Method section on printed page 147. The study assigned 68 fourth-grade children in one rural Midwestern school. One child in each innovative condition had an unavailable outcome because of illness or transfer. The package therefore contains 66 observed outcomes, with 22 per group; it provides no scores for the two unavailable outcomes.

The reference example selects one outcome and uses an unadjusted one-way model with a common within-group variance. The source study used several outcomes and pretest-adjusted analyses. Its integrated success criterion is invented for an imagined future replication: both DRA-referenced contrasts must have lower endpoints above zero in a two-sided 95% Bonferroni family. Applying that criterion to these historical records is a post hoc teaching analysis. It is not a prespecified decision attributed to the original investigators. Linking complete-outcome calculations to effects for all assigned children also requires a justification for the unavailable outcomes; a completion check alone does not establish that link.

Source and reuse. The browser obtains carData from the WebR package repository at run time. This note distributes no Baumann CSV or package copy. The package retains its upstream GPL version 2 or later terms, as stated on its CRAN page. Anyone redistributing the package or a derived extract should retain the applicable upstream terms and notices. The research article is cited, not redistributed, and its publication terms are separate from the package’s terms.

Review-timing data

Download the review-timing data (CSV) · Full codebook

This 36-case file preserves every score, factor code and case order from the generic SPSS_2way.sav in the 6020-25F26S teaching archive. The donor columns were Score, A and B. QMSBR added a sequential identifier and gave the factors the labels below. The Grade 7 fractions lesson, resource descriptions, review times, quiz interpretation and random assignment are invented for Chapter 4. The archived scores themselves were not newly simulated, and the source file does not document a real educational study or establish randomization.

Field Meaning and coding
student Added sequential case identifier, 1–36.
resource Original A: 1 = Textbook, 2 = Tutorial, 3 = Video.
timing Original B: 1 = Same day, 2 = Two days, 3 = One week.
score Original Score, unchanged. Values range from 7 to 20; the invented setting interprets them as numbers correct on a 20-item retention quiz.

There are four complete cases in each of the nine cells and no missing values. Scores sum to 407. In resource order Textbook, Tutorial, Video and timing order Same day, Two days, One week, cell means are (8.5000, 9.0000, 8.2500), (15.7500, 14.2500, 18.2500) and (9.7500, 9.7500, 8.2500). A full resource-by-timing model fits these records under independent-student, common-variance working assumptions. Normal errors give the exact classical F and t references. These archived scores are kept for reference consumers and the shared workspace; the Chapter 4 page does not use them.

Source and reuse. Retain the archived-file attribution and identify the educational setting as invented when adapting this example. The CC0 dedication for the separate Special Practice CSV does not apply to these archived scores. This note assigns no new licence to the donor file; QMSBR’s original descriptions and code retain the terms in LICENSE.
