# QMSBR

**Quantitative Methods for Social and Behavioral Research**, published at
<https://jinsong-chen.github.io/QMSBR/>.

This repository holds the rendered website that GitHub Pages serves: the
HTML pages, the chapter PDFs, the released data files and the R support
pages under `practice/`. The Quarto sources are maintained separately.

To report an accessibility barrier or another problem with a page, open an
issue here, naming the page and what got in the way.

third-party items keep their own terms ([LICENSE](LICENSE)). Maintained by
Jinsong Chen, Faculty of Education, The University of Hong Kong. QMSBR is
not an official University service.
